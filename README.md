# Salon Management API

A RESTful API for managing salons, services, and user authentication.

## Technologies

- Node.js
- Express.js
- Supabase
- JWT
- bcrypt

## Features

- User registration and authentication
- JWT-based authorization
- Salon management
- Service management
- Secure password hashing
- Supabase database integration
- RESTful API endpoints
